# 技能包 ZIP 文件名编码

Web、CLI 和 ClawHub 兼容入口支持中文目录名及文件名：

- 优先按 UTF-8 读取，包括未设置 UTF-8 标记的 UTF-8 ZIP。
- 文件名解码失败时，重新打开 ZIP，按 GBK 读取未设置 UTF-8 标记的条目。
- ZIP 中明确标记为 UTF-8 的条目始终按 UTF-8 读取。
- 路径安全、文件数量和大小校验在重试时继续执行；损坏的内容不会触发编码重试。

此兼容只处理 ZIP 文件名，不转换文件正文；文本文件仍应使用 UTF-8。
未标记编码的文件名按整个压缩包使用同一种编码处理。混合多种未标记编码的 ZIP 应重新打包为 UTF-8，避免名称歧义。
新建 ZIP 推荐使用 UTF-8，无需将中文名称改成英文。
